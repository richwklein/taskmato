# Trademarks

The Taskmato **source code** is open (see [`LICENSE`](LICENSE) and
[ADR-0012](docs/architecture/decisions/0012-pro-source-available-license-and-trademark.md)). The Taskmato
**identity** is not.

**"Taskmato", the Taskmato name, and the Taskmato app icon are trademarks of Richard Klein.** The MIT license
covering the code — and the Functional Source License covering the future `app/Taskmato/Pro/` subtree — grant
rights to the *source only*. Neither grants any right to these marks.

## What this means

- You may fork, build, modify, and (subject to the applicable code license) redistribute the source.
- A redistributed build — including a legally-forked MIT one — **may not** be called "Taskmato", use the
  Taskmato name in its product identity, or ship the Taskmato app icon.
- Rebrand a fork under your own name and icon before distributing it.
- Nominative references ("compatible with Taskmato", "a fork of Taskmato") are fine; branding your build *as*
  Taskmato is not.

This mirrors how projects such as Mozilla Firefox separate an open code license from a protected product
identity: the code is free to take, the brand is not.

Questions about permitted use of the marks: open an issue or contact the maintainer.
